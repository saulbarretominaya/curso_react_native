## React Native Paper
Librería de componentes de interfaz para React Native.
### Documentación
- NPM:
  https://www.npmjs.com/package/react-native-paper
- Documentación oficial:
  https://oss.callstack.com/react-native-paper/docs/guides/getting-started
### Versión utilizada
5.15.3
### Instalar
npm install react-native-paper@5.15.3
### Desinstalar
npm uninstall react-native-paper

## React Navigation
Librería para gestionar la navegación entre pantallas en aplicaciones React Native.
### Documentación oficial
https://reactnavigation.org/
### Versión utilizada
La versión que se instale compatible con el proyecto Expo actual.
### Instalar
npm install @react-navigation/native
npx expo install react-native-screens react-native-safe-area-context
npm install @react-navigation/native-stack
### Desinstalar
npm uninstall @react-navigation/native
npm uninstall @react-navigation/native-stack
