## React Native Paper
Librería de componentes de interfaz para React Native.
### Documentación
- NPM:
  https://www.npmjs.com/package/react-native-paper
- Documentación oficial:
  https://oss.callstack.com/react-native-paper/docs/guides/getting-started
### Versión utilizada
5.15.3
### Instalar
npm install react-native-paper@5.15.3
### Desinstalar
npm uninstall react-native-paper
---------------------------------------------------------------------
**## React Navigation**
Librería para gestionar la navegación entre pantallas en aplicaciones React Native.
**### Documentación oficial**
https://reactnavigation.org/
**### Instalar**
npm install @react-navigation/native
npx expo install react-native-screens react-native-safe-area-context
---------------------------------------------------------------------
**### Native Stack**
Navegador que permite gestionar las pantallas mediante una pila.
npm install @react-navigation/native-stack
**### Desinstalar**
npm uninstall @react-navigation/native
npm uninstall @react-navigation/native-stack
**## ---------------------------------------------------------------------**
**### Drawer Navigation**
Navegador que permite gestionar las pantallas mediante un menú lateral.
**### Dependencias**
npx expo install react-native-gesture-handler react-native-reanimated react-native-worklets
**### Instalar**
npm install @react-navigation/drawer
**### Desinstalar**
npm uninstall @react-navigation/drawer
npx expo uninstall react-native-gesture-handler react-native-reanimated react-native-worklets
**## ---------------------------------------------------------------------**
**### Bottom Tab Navigation**
Navegador que permite gestionar las pantallas mediante pestañas ubicadas en la parte inferior.
**### Instalar**
npm install @react-navigation/bottom-tabs
**### Desinstalar**
npm uninstall @react-navigation/bottom-tabs
